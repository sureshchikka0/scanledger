Privacy Policy

Effective 2 October 2026 · Applies to the ScanLedger app and this website

This policy explains what information the ScanLedger app (the "Tool") accesses, how it is used, stored and deleted, and how access can be revoked. The Tool is operated by Suresh, Hyderabad, India ("we", "us"), and is used only by the owner of the ScanLedger by Suresh YouTube channel.

1. YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Information the Tool accesses

The channel owner signs in once with Google (OAuth 2.0) and grants two permissions:

Permission (scope)What it is used for
youtube.uploadUploading the owner's own approved videos to the owner's own channel (videos.insert).
youtube.readonlyReading the owner's own channel details and statistics — channel name, subscriber count, view counts of the channel's own recent uploads (channels.list, playlistItems.list, videos.list).

The Tool does not access other users' accounts, viewers' personal information, comments, private messages, payment details, or any other channel's data.

3. How the information is used

  • To publish the channel owner's daily educational Short after the owner approves it.
  • To show the owner how their own channel is growing (subscribers and views over time).

The information is not sold, rented, shared with third parties, or used for advertising.

4. Storage and security

  • The OAuth access/refresh token is stored only on the channel owner's own computer, in a private folder that is not shared or published.
  • Channel statistics read through the API are stored in a private local database on the same computer, only while the authorization remains active.
  • This website does not use cookies, analytics or tracking, and collects no personal information from visitors.

5. Deletion and revoking access

  • Access can be revoked at any time from Google's security settings: https://security.google.com/settings/security/permissions.
  • When access is revoked, or on request by email, the stored token and all data obtained through YouTube API Services are deleted within 7 days.
  • Stored API data is refreshed or deleted at least every 30 days in line with the YouTube API Services Developer Policies.

6. Children

The Tool and this website are not directed at children under 13 (or under 18 in India) and do not knowingly collect their information.

7. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
