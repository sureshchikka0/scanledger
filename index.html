ScanLedger

Rule-based NSE scanners. Every signal time-stamped. Educational content only.

ScanLedger is a personal project by Suresh (Hyderabad, India). Each trading evening a set of rule-based scanners runs on end-of-day NSE data. The output is turned into plain charts and short, fact-based captions, reviewed by Suresh, and only then published to the ScanLedger channels.

How ScanLedger uses YouTube

ScanLedger Publisher is a private desktop tool used only by the owner of the ScanLedger by Suresh YouTube channel. It uses YouTube API Services to:

  • upload one short educational video (a YouTube Short) per trading day to that channel, after Suresh approves it;
  • read that channel's own basic statistics (subscribers, views) to track the channel's growth.

No other users sign in. No data about viewers or other channels is collected. Read the Privacy Policy and Terms of Use. By using YouTube features you also agree to the YouTube Terms of Service.
